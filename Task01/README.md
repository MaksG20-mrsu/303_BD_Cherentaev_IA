# Лабораторная работа №1

## Структура файлов данных

Каталог `Task01` содержит исходные файлы данных, скопированные из каталога `dataset`.

### ratings.csv

Файл содержит оценки пользователей за фильмы.

| Поле        | Описание                   |
| ----------- | -------------------------- |
| `userId`    | идентификатор пользователя |
| `movieId`   | идентификатор фильма       |
| `rating`    | оценка фильма              |
| `timestamp` | время выставления оценки   |

### Служебные файлы

* `ratings_count.txt` — содержит минимальный и максимальный идентификаторы пользователей и количество записей с каждым из этих идентификаторов.
* `sqlite.txt` — содержит версию установленной SQLite и список доступных режимов вывода данных.

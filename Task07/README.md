# Task07. PHP: консольное и веб-приложение для просмотра данных из БД

Приложение показывает список услуг, оказанных мастерами станции технического обслуживания
(база данных из лабораторной работы 6) с возможностью фильтрации по номеру мастера.

## Требования к окружению

- PHP 7.4 или новее (проверено на синтаксисе PHP 8.x) с расширениями `pdo_sqlite` и `sqlite3`
  (в Windows их нужно раскомментировать в `php.ini`: `extension=pdo_sqlite`, `extension=sqlite3`);
- расширение `mbstring` не требуется.

Проверка: `php -v` и `php -m` (в списке должны быть `PDO` и `pdo_sqlite`).

## Файлы

- `database.php` - подключение к БД через PDO и подготовленные запросы (общий код для обеих частей);
- `task7_cli.php` - консольный сценарий (таблица из символов псевдографики);
- `index.php` - веб-страница (HTML-шаблон с альтернативным синтаксисом PHP, без `echo`);
- `db_init.sql` - SQL-скрипт создания и заполнения базы (из лабораторной работы 6).

Файл базы `sto.db` создаётся автоматически при первом запуске из `db_init.sql`
(в репозиторий он не добавляется). Чтобы создать базу заново, достаточно удалить `sto.db`.

## Запуск

Консольное приложение (из каталога `Task07`):

```
php task7_cli.php
```

Программа выводит номера и ФИО всех мастеров из базы; нужно ввести номер мастера
либо нажать Enter, чтобы вывести работы всех мастеров. Некорректный ввод отклоняется.

Веб-приложение (встроенный сервер PHP, из каталога `Task07`):

```
php -S localhost:8000
```

Затем открыть в браузере http://localhost:8000/ . Мастер выбирается из раскрывающегося списка.

# Task08. PHP: веб-формы для ввода данных в БД

Веб-приложение станции технического обслуживания: формы для ввода мастеров, графика их
работы и предварительной записи клиентов. База данных SQLite - из лабораторной работы 6,
расширенная таблицей `master_services` (какие услуги может выполнять каждый мастер).

## Требования к окружению

- PHP 7.4 или новее с расширениями `pdo_sqlite` и `sqlite3`
  (в Windows их нужно раскомментировать в `php.ini`: `extension=pdo_sqlite`, `extension=sqlite3`);
- расширение `mbstring` не требуется.

## Структура

- `public/` - корень сайта (`index.php` - ссылки на формы, `master_form.php`,
  `schedule_form.php`, `appointment_form.php`, `style.css`);
- `src/` - подключение к БД (PDO, подготовленные запросы), проверка данных, вспомогательные функции;
- `templates/` - общая шапка и подвал страниц;
- `data/sto.db` - файл базы данных; `data/db_init.sql` - скрипт, из которого базу можно создать заново
  (если файла `sto.db` нет, он создаётся автоматически при первом открытии страницы).

## Запуск

Из каталога `Task08`:

```
php -S localhost:8000 -t public
```

Затем открыть в браузере http://localhost:8000/ .

## Формы

1. **Добавление мастера** (`master_form.php`) - ФИО, телефон, дата приёма, процент от выручки
   и услуги, которые мастер может выполнять (хотя бы одна). Ниже показан список мастеров.
2. **График работы** (`schedule_form.php`) - смена мастера на выбранную дату (начало и конец).
   На одну дату у мастера может быть только одна смена.
3. **Предварительная запись** (`appointment_form.php`) - сначала выбирается услуга, затем мастер
   (в списке только те, кто выполняет эту услугу), затем дата из графика мастера и свободное время
   (учитываются смена, длительность услуги и уже существующие записи), в конце вводятся данные
   клиента и автомобиля.

Все данные проверяются на сервере; занятость мастера дополнительно контролируют триггеры базы данных.
